# 谱聚类实验室 · Spectral Clustering Lab

> 顶级无监督学习 × 顶级数值线性代数：归一化拉普拉斯 + Lanczos 三对角化 + k-means 谱嵌入。

## 这是什么

谱聚类（Spectral Clustering，Ng–Jordan–Weiss 2001）把"聚类"问题转化为"图拉普拉斯的特征向量"问题：

1. 用 RBF 核把样本点建成**相似度图** `A`（`Aᵢⱼ = exp(−‖xᵢ−xⱼ‖² / 2σ²)`）。
2. 构造**归一化拉普拉斯** `L = I − D^{−1/2} A D^{−1/2}`（`D` 为度矩阵）。
3. 取 `L` 的 **k 个最小特征值**对应的特征向量，组成嵌入矩阵 `U`（每行单位化）。
4. 在 `U` 上跑 **k-means** 得到最终簇。

其中第 3 步的"取最小特征向量"由 **Lanczos 三对角化**完成——这是 Google PageRank、大规模特征值计算背后的同款算法：用 Krylov 子空间把大矩阵压缩成小三对角矩阵，再用 Jacobi 法求其特征对（Ritz 对），精度高、速度快。

## 核心不变量（已被 `_smoke.js` 证明）

| 不变量 | 含义 | 阈值 |
|---|---|---|
| `VᵀV ≈ I` | Lanczos 基正交 | `< 1e-8` |
| `‖MV − VT‖ = β_last` | Lanczos 残差等于最后 β | `< 1e-6` |
| Lanczos(满秩) = Jacobi | 特征值交叉验证 | `< 1e-6` |
| `L·√d = 0` | 拉普拉斯零空间 | `< 1e-9` |
| `λ₁ ≈ 0` | 连通图最小特征值为 0 | `< 1e-4` |
| 聚类忠实度 | 对照真值（blobs/rings） | `> 90%` |

## 使用

直接用浏览器打开 `index.html`：

- **数据集**：高斯团 (Blobs) / 同心环 (Rings) / 双月 (Moons)
- **n / k / σ / 种子**：样本数、簇数、RBF 核宽、随机种子
- **运行聚类** / **随机种子**：一键重算
- 三张图：原始散点（按预测簇着色）、谱嵌入（前 2 个特征向量）、拉普拉斯谱（最小 k 个特征值）
- 统计卡：最小特征值、谱间隙 `λ₂−λ₁`、对照真值忠实度、耗时

## 工程说明

- 引擎 `SPEC` 为纯函数、无 DOM 依赖，可嵌入任意项目。
- Lanczos 步数默认 `min(n, 80)`：blobs 类数据低维特征空间孤立，`m=40` 已足够；rings 类低特征值挨得近，需 `m≈80` 才收敛干净（实测 `m=40`→70.7%，`m=80`→100%）。
- 默认 `σ` 随数据集自适应：Blobs 1.0 / Rings 0.35 / Moons 0.12。
